白急線ポータル

shirakyurailway.html … ポータル本体（ダイヤデータ組み込み済み）
admin.html           … 運行管理（遅れの編集）。IDを知っている人だけが使えます
dev.html             … 開発情報
delay-config.js      … 遅延情報APIのURL（shirakyurailway.html と admin.html が共通で使う）
gas/Code.gs          … 遅延情報API（Google Apps Script）のコード
data/                … 元のダイヤデータ

すべて同じフォルダに置いてください。

■ 遅延情報を使えるようにする手順（最初の1回だけ）
1. https://script.google.com で「新しいプロジェクト」を作り、gas/Code.gs の中身を貼り付けて保存
2. 左の歯車「プロジェクトの設定」→ 下の「スクリプト プロパティ」→「プロパティを追加」
     プロパティ: ADMIN_ID　　値: 管理用のID（推測されにくい長めの文字列）
3. 右上「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
     次のユーザーとして実行: 自分　／　アクセスできるユーザー: 全員
   →「デプロイ」を押し、表示された「ウェブアプリのURL」（…/exec で終わる）をコピー
4. delay-config.js を開き、 window.DELAY_API = '（コピーしたURL）'; にして保存・アップロード

※ Code.gs を書き換えたときは「デプロイを管理」→ 編集 →「新バージョン」で更新すると、URLを変えずに反映できます。
※ IDはスクリプト側にだけ保存されるので、HTMLのソースを見られても漏れません。
※ delay-config.js が空のままなら、遅延表示は出ず、ポータルは今まで通り動きます。

■ 運休（運転見合わせ）（admin.html）
- 種類「運休（運転見合わせ）」で対象と開始時刻を入れて追加 →「保存して公開」
- 見合わせ中は対象の列車が開始時刻の位置で止まり、走行位置の上にお知らせが出る（まだ発車していない列車も発車しない）
- 一覧の「運転再開」を押すとすぐ公開され、止まっていた時間がそのまま遅れになる

■ 自動遅延（admin.html のスイッチで ON/OFF）
- ONにすると全路線でそれらしい遅れを自動で作る（日付と列番から決まる乱数のシミュレーション。見ている人全員に同じ遅れが出る）
- 朝夕ラッシュは遅れが出やすい。走行中は所要時間の約5%、停車中は停車時間を最短20秒まで詰めて回復運転する
- 折り返し（同じ運用の次の列車）に間に合わないときは次の列車も遅れる（折り返しの最低時間は2分）
- 手動の遅延・運休と同時に使える。OFFは翌日以降もOFFのまま、ONはONのまま

■ 区間と事象
- 「区間」で ○○駅〜○◇駅 を選ぶと、その区間を走る列車だけが対象になる（全線ならそのまま）
- 「事象」に「人身事故」などを入れると「○○駅〜○◇駅 人身事故が発生」と表示される
- 走行位置のいちばん下に「運行情報」として、事象と状況（運休／遅延）がまとめて出る

■ 遅れの付け方（admin.html）
- 路線を選び、対象（路線全体／上下線／種別／列車）と遅れ（分）を入れて「一覧に追加」→「保存して公開」
- 複数の設定が当たる列車は「列車 ＞ 種別 ＞ 上下線 ＞ 路線全体」の順で細かい方が優先。0分で「遅れなし」にできる
- 遅れはその運行日だけ有効で、翌朝4:00に自動で解除される
- ポータル側は1分ごとに読み直す（走行位置は遅れ分ずらした位置に表示）

■ 路線データの差し替え
shirakyurailway.html と admin.html の両方にダイヤが入っています。差し替えるときは両方とも更新してください。

■ 退避（追い越し）
・青波高速鉄道線だけに入れています。退避可能駅は 朝日ヶ丘・新森町・高輪平・花咲野・船渡川（上りはさらに港が丘）。
  変えるときは shirakyurailway.html の PASS_RULES を書き換えます。
・追い越す列車が遅れているときは、追い越されるまで退避駅で待ってから発車します（待った分は遅れとして表示）。
・追い越す列車が12分以上遅れているときは待たずに発車し、追いつかれる手前の退避可能駅で追い越させます。
  終点まで追いつかれない場合は、追い越しなしで走ります。
・走行位置と「○分遅れ」の表示だけに反映します（時刻表・乗換案内の時刻は変わりません）。

■ 一部区間で運転再開
・admin の一覧で「運休中」の行に出る「一部区間で再開」を押し、再開する区間を選んで「この区間で再開して公開」。
・選んだ区間は運転再開、残りの区間は見合わせのまま、設定が区間ごとに分かれます（残りも後で「運転再開」できます）。
・見合わせ中は、開始時刻に区間の中にいた列車はその場で止まり、区間に入っていない列車は区間の手前の駅で待ちます。
・事象の表示（「○○駅〜○◇駅 人身事故が発生」）は元の区間のままにするため、Code.gs の更新が必要です
  （Code.gs を貼り直し → デプロイを管理 → 新バージョンでデプロイ）。

■ 運転見合わせ中の列車の動き（青波高速・青波メトロ）
・区間の中にいた列車は、次の停車駅まで走ってそこで待ちます。
・当該列車（admin の「当該列車」に列番を入れたとき）はその場で止まり、後ろの列車は当該列車を追い越せません。
・区間に向かう列車は手前の折り返し駅で折り返し（行先に「（折返）」と出ます）、区間の向こう側の列車は、
  折り返してきた反対方向の列車で運転します（折り返しには最短1分30秒）。
・折り返しできる駅: 青波中央（全番線）、港が丘2・3番、朝日ヶ丘3番、高輪平3番、花咲野3・4番、船渡川3・4番、茶志内（全番線）。
  青波メトロ: 船渡川橋（全番線）、羽越台3番、光川（全番線）。
  変えるときは shirakyurailway.html と admin.html の TURNBACK を書き換えます。折り返し駅のない路線は区間の手前の駅で待ちます。
・当該列車と一部再開の区間を保存するため、Code.gs の更新が必要です（貼り直して新バージョンでデプロイ）。

■ 運輸司令（shirei.html）
・運行管理（admin.html）右上の「運輸司令」から開きます。ログインIDは運行管理と同じです。
・青波高速鉄道線・白急桜田線・白急みやこ線の配線図に、いま走っている列車を表示します（10秒ごとに更新）。
・列車をタップすると、入線番線（これから通る駅ごと）・行先（途中止まりにする）・種別を変えて公開できます。
・「この列車を抑止する」で、駅にいればその駅で、駅間ならその場で止めます。「抑止を解除」で動き出し、止まっていた分だけ遅れます。
・配線図の列車は、駅の分岐や渡り線も含めて線路の上を通って動きます。
  走行位置の表示（種別マーク・行先・番線）に反映されます。時刻表・駅時刻表は変わりません。
・変更はその日の運行日のあいだだけ有効です（翌朝4:00に消えます）。
・保存のため Code.gs の更新が必要です（貼り直して新バージョンでデプロイ）。抑止の保存には 2026-11-16 夕方以降の Code.gs が必要です。

■ 運輸司令でできる変更（2026-11-17）
・列番の入力欄から、走っていない列車（発車前の列車）も開いて変更できます。
・種別、行先、停車駅（駅ごとに 停車/通過）、着時刻・発時刻、入線番線を変えられます。
  発時刻を変えると、その先の駅も同じだけずれます。通過を停車にすると30秒停車します。
・入換: 駅に止まっている（発車待ちの）列車を、その駅の別の番線へ移します。
・停車駅と時刻の変更の保存には、2026-11-17 以降の Code.gs が必要です（貼り直して新バージョンでデプロイ）。
・青波中央・茶志内に引上1〜7、船渡川に引上3-1〜4-3と車庫を追加（入換・番線変更で選べます。shirakyurailway.html の EXTRA_TRACKS）。
・同じ線路の上では追い越しません（駅間は先に出た列車より先に着かない。駅は同じ番線なら前の列車が出てから入る。番線が違えば追い越せます）。

■ 運休・途中駅から運転・運用を開く・自動の運転整理（2026-11-17 夜）
・運輸司令で列車を「運休」にできます。「始発」を変えると途中駅から運転します（手前は運休）。
・検索欄に運用番号（N22 など）を入れると、その運用の列車が順に並び、列車を開いて変更できます。
・自動の運転整理（遅れたとき）:
  段落とし … 折り返しの編成が間に合わないとき、その駅に着いている別の編成で定刻に発車する。
  山切り   … それでも5分以上遅れるとき、遅れた列車を手前の折り返し駅で打ち切り、折り返し列車をその駅から定刻で出す
             （同じ終点では、山切りのあと2本は山切りしない）。
  どちらもできなければ、折り返しの列車を遅らせる。
・運休と途中駅から運転の保存には、この日以降の Code.gs（code.txt）が必要です。

■ 白糸線（2026-11-22 追加）
・朝日ヶ丘〜白糸温泉。稲見から先は単線（交換駅: 瀬戸口・梶が森）。
・列車番号は始発の早い順に 下り 801H, 803H… 上り 802H, 804H… を自動で振っています。
・両数は H=2両、N=4両、P=3両。運用表は N81〜84、H04〜05、P01〜06 の順に表示します。
・稲見の引上線は略称が両方「引」だったため、収録データでは「引2」「引3」に分けています。
・運輸司令（shirei.html）に白糸線のタブを追加。単線区間の交換待ち・行き違いの自動調整は未対応です。
